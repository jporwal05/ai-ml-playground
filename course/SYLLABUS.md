# Syllabus — Learn ML & AI by Building It

Each lesson is one small concept you build yourself. Lessons go in order; each one uses the ones before it.

**Start here:** [Setup guide](SETUP.md) — install Python and the tools.

## Part 1 — How a machine learns (one input)
1. [**What is ML?**](../concepts/01-what-is-ml/README.md) — Writing rules by hand vs. learning them from data.
2. [**A model is just a function**](../concepts/02-model-is-a-function/README.md) — Predicting with a line: y = mx + b.
3. [**Loss**](../concepts/03-loss/README.md) — One number that says "how wrong" the model is.
4. **Derivatives as direction** — Which way is downhill?
5. **Gradient descent** — Walking downhill step by step to reduce loss.
6. **Build: linear regression from scratch**

## Part 2 — Many inputs
7. **Vectors & the dot product**
8. **Matrices** — What a matrix *does* to points.
9. **Classification & the sigmoid**
10. **Build: logistic regression**

## Part 3 — Neural networks
11. **A neuron**
12. **Activation functions**
13. **Layers as matrix multiplication**
14. **Backpropagation**
15. **Overfitting & train/test split**
16. **Build: a handwritten digit recognizer from scratch**

## Part 4 — Using the GPU
17. **PyTorch tensors & autograd**
18. **Build: the digit recognizer on the GPU**

## Later
CNNs → embeddings → attention → transformers → a tiny GPT of your own.
