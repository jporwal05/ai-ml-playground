# Analogies

Every analogy used in the course, indexed by concept.

| Concept | Analogy | Lesson |
|---|---|---|
| Setup: uv & virtual environments | uv is a kitchen manager: it fetches the right stove (Python) and gives each project its own lunchbox (`.venv`) of libraries. | [Setup](SETUP.md) |
| Machine learning | Teaching a child what a "dog" is by showing examples, not giving a rulebook. | [01](../concepts/01-what-is-ml/README.md) |
| Normal programming vs ML | ML flips the arrows: rules + data → answers becomes data + answers → rules. | [01](../concepts/01-what-is-ml/README.md) |
| Model & parameters | A machine with knobs; learning = turning the knobs until the predictions match. | [01](../concepts/01-what-is-ml/README.md) |
| Model as a function | A taxi fare meter: input (km) changes every ride; knobs (per-km rate, base fare) change only when the meter is re-tuned (training). | [02](../concepts/02-model-is-a-function/README.md) |
| Using vs training a model | A phone plan: using more GB changes x; only the company changing the plan changes m and b. | [02](../concepts/02-model-is-a-function/README.md) |
| Weight & bias | Per-km rate (weight/slope) and base fare (bias/intercept). | [02](../concepts/02-model-is-a-function/README.md) |
| Loss | A golf score: a whole round of mistakes becomes one number, and lower is better. | [03](../concepts/03-loss/README.md) |
| Squaring the misses (MSE) | A speeding fine that grows fast: 5 over is cheap, 20 over is very expensive. | [03](../concepts/03-loss/README.md) |
| Squared error | The area of a square drawn on each miss: big gaps make huge squares. | [03](../concepts/03-loss/README.md) |
| Loss curve | A valley you stand in blindfolded: you find downhill by feeling the tilt under your feet. | [03](../concepts/03-loss/README.md) |
| Derivative / slope | Blindfolded on a hillside: slide your foot a tiny bit and feel whether the ground goes up or down, and by how much. | [04](../concepts/04-derivatives/README.md) |
| Tangent line | A rigid skateboard resting on a bowl: it touches at one spot, has the bowl's tilt there, and doesn't bend. Tilted down-right = it would roll right. | [04](../concepts/04-derivatives/README.md) |
| Why tangents stay straight | A taxi meter that kept re-tuning its rate every km would bend; a tangent uses one fixed tilt measured at the spot. | [04](../concepts/04-derivatives/README.md) |
